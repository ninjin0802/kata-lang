03 字句と文法

この章は M1 の文法を定める。空白と改行に意味はない。

全体の例

module app.counter;

import kata.ui.Button;
import kata.ui.Column;
import kata.ui.Screen;
import kata.ui.Text;
import kata.ui.Ui;

class Counter implements Screen {
  var count: Int = 0;

  fn view(self) -> Ui {
    return Column {
      children: [
        Text { text: self.count.toString() },
        Button { label: "+1", onTap: self.increment },
        Button { label: "Reset", onTap: self.reset },
      ],
    };
  }

  fn increment(self) -> Unit {
    self.count = self.count + 1;
  }

  fn reset(self) -> Unit {
    self.count = 0;
  }
}

app {
  id: "dev.kata.counter",
  name: "Counter",
  root: Counter {},
}

ソースファイル

  • 拡張子は .kata、文字コードは UTF-8。
  • 空白（スペース、タブ、改行）はトークンの区切りとしてだけ働く。
  • コメントは // から行末まで。ブロックコメントはない。

識別子

種類形使う場所
LowerIdent[a-z][A-Za-z0-9]*変数、引数、フィールド、メソッド、モジュール名の各部分
UpperIdent[A-Z][A-Za-z0-9]*型（クラス、インターフェース、組み込み型）

先頭の文字の大小で種類が決まる。アンダースコアは使えない。

予約語

区分語
M1 で使うmodule import class implements let var fn self return if else while for in true false app enum match
M2 以降のために予約interface break continue

予約語は識別子に使えない。ただし app は、モジュール名の一部としてだけ使える（module app.counter;）。M2 以降の予約語を書くと E0105 になる。

リテラル

種類形補足
整数0 または [1-9][0-9]*範囲は 0 から 9223372036854775807。負の数は単項の - で書く。
小数整数 "." 数字の並び（1.5、0.25、3.0）小数点の前後の両方に数字が要る。指数表記はない。整数部の先頭に余分な 0 は書けない。Float で表せない大きさは E0104。負の数は単項の - で書く。
文字列"..."ASCII 以外の文字（日本語、記号、絵文字）もそのまま書ける。エスケープは \" \\ \n \t の4つ。改行をそのまま含めることはできない。式の埋め込みはない。
真偽値true false

記号

{ } ( ) [ ] < > , ; : . = -> =>
+ - * / %
== != < <= > >=
&& || !

文法

型引数を閉じる > の直後に = が続く場合（List<Int>= []）も、> と = として読む。

記法：[ x ] は省略可、{ x } は0回以上の繰り返し、| は選択。

ファイル

file        = moduleDecl { importDecl } { classDecl | enumDecl } [ appDecl ] EOF ;
moduleDecl  = "module" modulePath ";" ;
modulePath  = LowerIdent { "." LowerIdent } ;
importDecl  = "import" modulePath "." UpperIdent ";" ;

宣言の順番は固定で、module、import、class と enum（この2つは混ぜてよい）、app の順に書く。

enum

enumDecl    = "enum" UpperIdent "{" variant { "," variant } [ "," ] "}" ;
variant     = UpperIdent [ "{" [ param { "," param } [ "," ] ] "}" ] ;

クラス

classDecl   = "class" UpperIdent [ "implements" UpperIdent { "," UpperIdent } ]
              "{" { fieldDecl } { methodDecl } "}" ;
fieldDecl   = ( "let" | "var" ) LowerIdent ":" type [ "=" expr ] ";" ;
methodDecl  = "fn" LowerIdent "(" "self" { "," param } [ "," ] ")" "->" type block ;
param       = LowerIdent ":" type ;
type        = UpperIdent [ "<" type { "," type } ">" ] ;

クラスの中では、フィールドをすべて書いてからメソッドを書く。

文

block       = "{" { stmt } "}" ;
stmt        = letStmt | varStmt | assignStmt | returnStmt | ifStmt
            | whileStmt | forStmt | matchStmt | exprStmt ;
letStmt     = "let" LowerIdent ":" type "=" expr ";" ;
varStmt     = "var" LowerIdent ":" type "=" expr ";" ;
assignStmt  = postfix "=" expr ";" ;
returnStmt  = "return" [ expr ] ";" ;
ifStmt      = "if" "(" expr ")" block [ "else" ( block | ifStmt ) ] ;
whileStmt   = "while" "(" expr ")" block ;
forStmt     = "for" "(" LowerIdent ":" type "in" expr ")" block ;
matchStmt   = "match" "(" expr ")" "{" { arm } "}" ;
arm         = UpperIdent "." UpperIdent [ "{" [ LowerIdent { "," LowerIdent } [ "," ] ] "}" ] "=>" block ;
exprStmt    = postfix ";" ;
  • if と while の条件、for の見出しは必ず括弧で囲む。if は文であり、値を返さない。
  • for の変数にも型を書く（for (item: Int in self.history) { ... }）。
  • 単純な文とフィールド宣言は必ず ; で終える。if、while、for とブロックの後には付けない。

式

expr        = unary [ binOp unary { binOp unary } ] ;
unary       = ( "-" | "!" ) unary | postfix ;
postfix     = primary { "." LowerIdent [ args ] } ;
args        = "(" [ arg { "," arg } [ "," ] ] ")" ;
arg         = LowerIdent ":" expr ;
primary     = IntLit | FloatLit | StringLit | "true" | "false" | "self" | LowerIdent
            | construct | enumValue | listLit | "(" expr ")" ;
enumValue   = UpperIdent "." UpperIdent [ "{" [ fieldInit { "," fieldInit } [ "," ] ] "}" ] ;
construct   = UpperIdent "{" [ fieldInit { "," fieldInit } [ "," ] ] "}" ;
fieldInit   = LowerIdent ":" expr ;
listLit     = "[" [ expr { "," expr } [ "," ] ] "]" ;
binOp       = "+" | "-" | "*" | "/" | "%"
            | "==" | "!=" | "<" | "<=" | ">" | ">="
            | "&&" | "||" ;

演算子の並べ方

演算子に優先順位はない。括弧のない1つの式に並べられるのは、次の場合だけ。

  • +、*、&&、|| は、同じ演算子だけを何個でも並べられる（a + b + c）。
  • それ以外の二項演算子は、1つの式に1回だけ使える（a - b、a < b）。
書いたもの結果直し方
a + b * cE0203a + (b * c)
a - b - cE0204(a - b) - c
a < b && c < dE0203(a < b) && (c < d)

単項演算子は直後の unary にだけ掛かる。-a + b は (-a) + b を意味する。

app 宣言

appDecl     = "app" "{" fieldInit { "," fieldInit } [ "," ] "}" ;

書ける項目と順番は 05 UI とアプリモデルで定める。

末尾のカンマ

引数、構築式、リスト、app 宣言では、最後の要素の後のカンマを書いても書かなくてもよい。原則 P1 の唯一の例外とする。どちらも意味は同じで、禁止しても読みやすさは変わらず、往復が増えるだけだからである。

名前付きの規則

  • メソッド呼び出しの引数は、すべて 名前: 式 の形で書く。位置だけで渡すことはできない（E0205）。
  • 引数と構築式の項目は、宣言された順番で書く。順番の規則は 04 型と意味論で定める。
