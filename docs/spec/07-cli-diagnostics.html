07 コマンドと診断

kata コマンドの出力は、エージェントが読んでそのまま修正に使える形にする。

コマンド

コマンド内容
kata check <プロジェクト>検査だけを行う。ファイルは書き出さない。Android SDK は不要。
kata build <プロジェクト>検査し、通れば build/app.apk まで作る。
  • 結果は、標準出力に JSON を1つ出力する。人間向けの表示形式は持たない。
  • 外部ツールの出力などの補足は標準エラーに出す。

終了コード

値意味
0成功。診断なし。
1診断が1件以上ある。
2コマンドの使い方の誤り（引数の不足、プロジェクトに src/ がないなど）。JSON は出力せず、標準エラーに説明を出す。

出力の形

{
  "ok": false,
  "artifact": null,
  "diagnostics": [
    {
      "code": "E0401",
      "message": "type mismatch",
      "file": "src/app/counter.kata",
      "line": 15,
      "column": 22,
      "endLine": 15,
      "endColumn": 32,
      "expected": "String",
      "found": "Int",
      "fix": {
        "line": 15,
        "column": 22,
        "endLine": 15,
        "endColumn": 32,
        "replacement": "self.count.toString()"
      }
    }
  ]
}
項目内容
ok診断が0件なら true。
artifactkata build が成功したときの APK のパス（プロジェクトからの相対パス）。それ以外は null。
code診断コード。意味は変えない。廃止したコードの番号は再利用しない。
message英語の短い説明。同じコードでも状況に応じて変わる。
fileプロジェクトからの相対パス。ファイルに結び付かない診断では null。
line column endLine endColumn範囲。行と列は1始まりで、列は Unicode のコードポイント単位。終わりの位置は範囲に含まない。file が null のときはすべて null。
expected found期待したものと実際のもの。型の名前や、トークンの候補。該当しなければ null。
fix機械的に決まる修正。範囲を replacement で置き換える。決まらなければ null。
  • 診断は、ファイルのパス、行、列の順に並べる。
  • fix は、適用すればその診断が解消することを保証する。他の診断が残ることはある。
  • fix は行の区切りを前提にしない。import の追加は、最後の import（なければ module 宣言）の直後に改行と import 文を挿入する。import の削除は、その import 文の範囲だけを取り除く。
  • コンパイラ自体が失敗した場合も、E0999 を1件持つ JSON を出力し、終了コード 1 で終わる。

診断を返す範囲

  1. 全ファイルの字句解析を行い、字句の診断がなかったファイルの構文解析を行う（字句の誤りが原因の構文の診断を重ねて出さないため）。構文解析は、文とメンバーの区切り（; と }）で立て直して続け、見つかった診断をすべて集める。
  2. ここまでで診断が1件でもあれば、それを返して終わる。
  3. なければ検査を行い、見つかった診断をすべて返す。
  4. kata build は、診断が0件のときだけコード生成以降に進む。

診断コード一覧

E01xx 字句

コード内容fix
E0101使えない文字がある。なし
E0102文字列リテラルが閉じていない。なし
E0103使えないエスケープがある。なし
E0104整数または小数のリテラルが範囲外、または先頭に余分な 0 がある。なし
E0105M2 以降のために予約された語を使っている。なし

E02xx 構文

コード内容fix
E0201予期しないトークン。expected に候補を入れる。なし
E0202; がない。; の挿入
E0203種類の違う演算子を括弧なしで混ぜている。なし
E0204並べられない演算子を2回以上使っている。なし
E0205引数に名前がない。なし
E0206式だけの文が、Unit を返すメソッド呼び出しではない。なし

E03xx 名前

コード内容fix
E0301未定義の名前。なし
E0302未定義の型。なし
E0303名前の重複（クラス、メンバー、引数、ローカル変数。シャドーイングを含む）。なし
E0304フィールドまたはメソッドに self. が付いていない。self. の挿入
E0305kata.ui の名前を import せずに使っている。import 文の挿入
E0306使っていない import がある。import 文の削除
E0307import したモジュールまたは名前が存在しない。なし

E04xx 型

コード内容fix
E0401型が合わない。expected と found に型を入れる。String の場所に Int か Float がある場合は .toString() の付加。Float の場所に Int がある場合は .toFloat() の付加
E0402演算子のオペランドの型が合わない。String 同士の + は concat への置き換え
E0403if または while の条件が Bool ではない。なし
E0404return で終わらない経路がある。なし
E0405return の値の有無が戻り値の型と合わない。なし
E0406リスト記法の型が周囲から決まらない。なし
E0407Unit を戻り値の型以外に使っている。なし
E0408型引数の数が合わない。なし
E0409return の後ろに文がある。なし

E05xx クラスとメンバー

コード内容fix
E0501その型に存在しないフィールドまたはメソッド。なし
E0502引数の不足、未知の名前、順番の違い。expected に正しい名前の並びを入れる。順番だけが違う場合は並べ替えた引数リスト
E0503構築式の項目の不足、未知の項目、初期化の式を持つフィールドの指定、順番の違い。expected に正しい名前の並びを入れる。順番だけが違う場合は並べ替えた項目リスト
E0504書き換えられないもの（let、引数）への代入。なし
E0505self 以外のオブジェクトのフィールドへの代入。なし
E0506インターフェースを満たしていない、または実装できないインターフェースを指定している。なし
E0507メソッド参照の対象が、self 以外の引数が0個か1個で Unit を返すメソッドではない。なし
E0508フィールドに引数リストを付けている。なし
E0509フィールドの初期化の式で self を使っている。なし

E06xx プロジェクトと app 宣言

コード内容fix
E0601module 宣言の名前がファイルの位置と合わない、または予約された kata で始まる。位置と合わない場合は、正しいモジュール名への置き換え
E0602app 宣言がない、または2つ以上ある。なし
E0603app 宣言の項目の不足、未知の項目、順番の違い、id または name の形の誤り。なし
E0604root が Screen に代入できない。なし

E09xx 環境とツール

kata build だけが返す。file は null。

コード内容
E0901ANDROID_HOME が未設定、またはその場所が存在しない。
E0902必要な SDK の部品（platforms/android-35、build-tools/35.0.0）がない。
E0903外部ツール（d8、aapt2、zipalign、apksigner、keytool）が失敗した。message にツール名と出力を入れる。build/ の中にシンボリックリンクがあってビルドを止めた場合もこのコード。
E0999コンパイラ内部の誤り。検査を通ったプログラムでコード生成が失敗した場合を含む。コンパイラの不具合である。
