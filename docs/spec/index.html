kata 仕様書

AI エージェントが読み書きすることを前提にした、Android 向けのオブジェクト指向言語。

この仕様書の位置づけ（SSOT）

  • この docs/spec/ が kata の唯一の正とする。コンパイラ、ランタイム、テスト、サンプルはすべてここに従う。
  • 実装と仕様が食い違ったら、仕様が正しい。仕様のほうが誤っていると分かった場合は、先に仕様を直し、同じコミットで実装を合わせる。
  • 言語や出力形式を変える変更は、仕様の変更を必ず含める。仕様に書かれていない挙動を実装に入れない。
  • 章は1ファイルに分ける。各節には固定の id を付け、コードやコミットからは 04-semantics.html#mutability の形で参照する。
  • 機能には実装段階を示す印を付ける。M1 は最初のマイルストーンで実装するもの、M2 はそれ以降のもの。
