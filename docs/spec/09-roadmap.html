09 ロードマップ

M1 の完了条件

  1. 03 の例と同じ内容の examples/counter/src/app/counter.kata が、kata check で診断0件になる。
  2. kata build examples/counter が build/app.apk を出力する。
  3. scripts/e2e.sh がエミュレータ上で成功する（表示が 0 → 1 → 0 と変わる。回転しても表示が保たれる。examples/styled の大きさ、余白、色、配置が指定どおりになる。examples/form で入力とスクロールができ、再描画でフォーカスとスクロールの位置が保たれる）。
  4. ./gradlew test が成功し、E01xx から E06xx の全診断コードに照合テストがある。
  5. 実装が 03 から 07 の M1 の規則と一致している。

UI の拡充引っ張って更新、動画、地図、カメラ、値を指定したアニメーション、標準のアイコン集、大量の項目を効率よく表示する一覧、プロセス終了をまたいだ状態の保存。
副作用通信、保存、時刻など。
